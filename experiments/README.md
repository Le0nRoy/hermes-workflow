# Сравнительные испытания

Рабочий пакет: [process-comparison/PROTOCOL.md](process-comparison/PROTOCOL.md).
API/flaky-контроли проверены; UI и квотный допуск пока блокируют приёмку пакета.

## Кандидаты
1. Переносимые скиллы Tortuga-AI.
2. make-feature Миллера.
3. bulletproof Миллера.

Использовать как альтернативы. Не добавлять обязательный Superpowers-процесс поверх кандидатов. Проверку актуального Superpowers провести позже отдельно при необходимости.

## Задания
Подготовить API-задачу, UI-сценарий и исправление нестабильного теста. Для всех кандидатов фиксировать одинаковые требования и исходное состояние. По возможности использовать известные дефекты для проверки полезности тестов, а не только зелёного результата.

## Что записывать для каждого запуска
- Задание, критерии приёмки, исходный commit и тестовые данные без секретов.
- Версия Hermes, модель/провайдер, версия скилла и его локальные адаптации.
- Условия доступа, время начала/окончания, остановки по лимитам.
- Результаты реальных тестов, найденные и пропущенные дефекты, повторяемость.
- Вмешательства владельца, переделки, измеренный расход квоты/денег; неизвестное помечать неизвестным.
- Артефакты и итог приёмки.

Не смешивать результат проверки инфраструктуры с качеством методологии. Исходные результаты пока отсутствуют. Сырые логи, клиентские данные и большие артефакты не коммитить.
