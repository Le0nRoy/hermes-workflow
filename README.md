# Hermes Workflow

Проект настройки и испытания Hermes + Hermes Kanban для фриланса по автоматизации API/UI-тестирования. Развивается параллельно Tortuga-AI.

## Состояние
Создан только каркас. Профили, модели, диспетчер Kanban, изоляция и мониторинг ещё не настроены и не проверены в рамках этого проекта.
Правила работы агента находятся в [AGENTS.md](AGENTS.md). Файл создан после отдельного подтверждения владельца.

## Границы хранения
В репозитории: документация, будущие исходники адаптированных скиллов, безопасные шаблоны конфигураций и скрипты проверки/развёртывания.
Вне репозитория: секреты, живые настройки и базы Hermes, сессии, клиентские материалы, временные артефакты.

Будущие config/, skills/, scripts/ и tests/ создаются по мере появления реальных файлов. Локальный Git не заменяет резервное копирование.
